\# Vehicle Service Management System



\## Project Description

The Vehicle Service Management System is a web-based application designed to manage vehicle servicing records, customer details, service status, and billing information.



\## Technologies Used

\- HTML

\- CSS

\- JavaScript

\- Node.js

\- Express.js



\## Features

\- Dashboard with service statistics

\- Add and manage service records

\- Track pending and completed services

\- Manage billing and payment status

\- Calculate service revenue



\## How to Run

1\. Install Node.js.

2\. Open the project folder in CMD.

3\. Run `npm install`.

4\. Run `node server.js`.

5\. Open `http://localhost:3000` in your browser.



\## Note

Service records are stored in memory and are cleared when the server restarts.
